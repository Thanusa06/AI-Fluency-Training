
# AI Fluency Training Handbook

## Introduction
AI fluency means understanding how to use artificial intelligence tools effectively, responsibly, and safely.

## Large Language Models
A large language model (LLM) processes text and generates responses based on patterns learned during training. Its answers can be incorrect, so important information should be verified.

## Chatbots, Workflows, and Agents
- A chatbot responds to user messages.
- A rule-based workflow follows predefined steps.
- An AI agent can use tools and observations to work toward a goal.

## Agent Components
An AI agent commonly includes a language model, tools, and a control loop. The agent may reason about a task, call a tool, observe its result, and decide what to do next.

## Responsible AI
- Verify important information.
- Protect API keys and private data.
- Do not treat generated answers as automatically correct.
- Follow institutional rules when using AI for assignments.
