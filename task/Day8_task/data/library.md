
# College Library Rules

## Library Access
Students can use the college library for reading, studying, and accessing learning resources during the library's operating hours.

## Borrowing Books
Students must use their college ID when borrowing books. All borrowed books must be returned by the due date.

## Book Care
Students must handle library books carefully. Writing in books, damaging pages, or removing library materials without permission is prohibited.

## Silence and Discipline
- Maintain silence in reading areas.
- Keep mobile phones on silent mode.
- Do not disturb other readers.
- Keep desks and reading spaces clean.

## Late Returns
Students should check the library's current borrowing and overdue rules with library staff.

## Important Note
This is sample handbook content for the Day 8 training task, not an official college library policy.
